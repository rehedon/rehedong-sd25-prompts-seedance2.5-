# 热河东 sd2.5 提示词

把**剧本、画布参考素材和人物表演意图**，整理成适用于即梦 Seedance 2.5 多参／全能参考的影视视频提示词。

**单次最长30秒 · 默认无精准时间戳 · 多参绑定 · 情绪与真实表演 · 末尾负面提示词**

[下载完整 Skill](https://github.com/rehedon/rehedong-sd25-prompts-seedance2.5-/releases/latest) · [阅读主要规则](rehedong-seedance-25/SKILL.md) · [查看完整示例](rehedong-seedance-25/references/examples.md)

当前 Skill 版本：**v2.1.1**。维护者：**热河东**。

## 这个项目做什么

这是一个供 AI 助手读取的 Skill，主要服务于影视短片、剧情镜头和连续片段的提示词创作。提供剧本、角色与场景参考，以及需要覆盖的剧情范围后，助手会组织素材职责、场面调度、人物表情、动作、镜头和声音，输出完整的导演提示词。

创作重点是让情绪通过行为被看见：角色先注意到什么，怎样呼吸、停顿、握住道具，又如何把情绪带进接下来的动作和声音。人物身份、原台词、事件因果和道具归属同时得到保留。

输出的提示词由你绑定实际素材、设置画布参数并提交到即梦生成。本项目交付的是提示词工作流。

## 适合哪些创作

- 将剧本中的一个镜头、一段场景或前30秒转为视频提示词。
- 在画布里使用多个人物、场景、动作视频或声音参考。
- 编排对白、哭唱、倾听、犹豫、情绪转折等人物表演。
- 将更长的剧情拆成多段视频，保持人物、空间、道具和声音的衔接。

也包含视频编辑、延长、首尾帧、宫格和白模等专项规则，详见 [任务模式](rehedong-seedance-25/references/task-modes.md)。

## 主要特点

| 特点 | 具体做法 |
|---|---|
| 画布多参优先 | 每份素材说明对应的角色或对象，以及控制身份、空间、动作或声音的哪个维度。 |
| 单次生成最长30秒 | 可以更短；超长需求按剧情拆成多份独立提示词，保留每段的承接状态。 |
| 默认无精准时间戳 | 用“开场、看清之后、情绪转折、收束”和动作完成条件安排节奏。 |
| 情绪有过程 | 连接情绪起点、触发事件、可观察反应、应对动作与情绪落点。 |
| 真实感有依据 | 同时关注心理因果、身体接触与重心、材质和光线的一致性。 |
| 故事与素材保真 | 保留原台词、角色数量、事件结果和道具归属；已知素材引用沿用原编号。 |
| 末尾附负面提示词 | 针对当前镜头的串脸、表情突跳、穿模、道具瞬移、时序或声音错误编写。 |

**30秒是本项目的工作流上限。** 不同入口的平台能力与参数以实际界面为准；本 Skill 对更长内容采用分段生成。

## 怎样提供素材

提供三类信息就能开始：**剧情内容、素材职责、创作范围**。实际素材编号已知时直接填写；只有剧本时也可以先写画布待绑定稿。

下面是一个虚构的使用示例，`@图片1` 等编号仅演示绑定方式，使用时替换成自己画布里的真实引用：

```text
请用 $rehedong-seedance-25 写一个30秒以内的剧情片段。

剧情：女儿站在老屋门口，说：“我回来了。”
母亲抬头看她，放下手里的碗，想靠近却停住。

画布绑定：
@图片1：女儿的面孔、发型与服装。
@图片2：母亲的面孔、发型与服装。
@图片3：老屋的布局、门口与餐桌的空间关系。

要求：保留原台词，不添加新对白。让母亲的停顿、视线和身体重心
呈现想靠近又犹豫的状态。保持参考人物的身份，默认不用精准时间戳，
提示词最后附本段的负面提示词。
```

没有实际标签时，会使用 `〔女儿人物参考〕` 等语义槽位，并明确标注为**画布待绑定稿**。提交生成前，将这些槽位替换为真实引用。完整绑定方法见 [画布多参说明](rehedong-seedance-25/references/canvas-reference.md)。

## 会得到怎样的提示词

默认输出按以下结构组织。具体阶段数量随剧情变化，单镜头可以更简洁；每份提示词的末尾都保留负面板块。

```text
【总述】
主体、地点、核心事件、情绪变化与镜头形式。

【多模态参考层】
逐份绑定人物、场景、关键物件、动作与声音素材。

【全局设定】
环境与质感、风格与光线、镜头语言、人物造型、表演核心、声音原则。

【情绪与动作分镜】
按因果推进的自然阶段：动作与表情、镜头与声音、表演意图、承接状态。

【全局收束】
贯穿片段的身份、空间、道具和声画关系。

【负面提示词】
本段需要避免的具体生成错误。
```

例如，表达“想靠近又犹豫”，可以写成下面这样的表演指令：

> 母亲听见声音后抬眼，目光停在女儿脸上；手里的碗轻轻落回桌面。她上身先向门口倾去，脚步却停在原地，吸了一口气，没有马上接话。镜头留在能看清她视线和身体重心的中近景。
>
> 表演意图：靠近的愿望先从身体里出现，犹豫随后把动作截住。

更多成品形态见 [完整示例](rehedong-seedance-25/references/examples.md)，表演与摄影方法见 [导演写法](rehedong-seedance-25/references/film-direction.md)。

## 常见问题

**超过30秒的剧情怎么处理？** 说明整体剧情和目标时长，Skill 会拆成多份独立提示词，每份最长30秒，并写清段落衔接；对白和动作需要自然展开的空间。

**一定要先准备所有参考图吗？** 可以先给剧本，得到明确标识的待绑定稿；已有真实标签时会保留原引用。用户明确要求纯文字生成时，会省略参考层。

**能要求精准时间戳吗？** 可以在本次请求中明确提出。默认采用自然阶段；已有明确的编辑生效区间仍按原范围保留。

**负面提示词会固定禁用音乐、字幕或哭喊吗？** 按当前镜头选择需要避免的错误，保留剧情需要的声音、文字和表演。负面板块属于提示词文本，使用时按实际生成入口填写。
