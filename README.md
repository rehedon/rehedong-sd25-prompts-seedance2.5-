# 热河东 sd2.5 提示词

面向即梦 Seedance 2.5 画布多参／全能参考的影视提示词 skill，重点编排人物情绪、表情、真实表演和镜头连续性。

当前版本：**2.1.1**。

## 核心规则

- 单次生成视频最长 **30 秒**；更长内容拆为多份独立提示词，保持段落衔接。
- 默认不用精准时间戳，以动作完成条件、情绪转折与相对节奏组织。
- 默认使用多模态参考层、全局设定、情绪与动作分镜、全局收束。
- 每份提示词最后附 **负面提示词** 板块，针对当前镜头编写。
- 保留原台词、故事因果、角色身份与道具归属；缺少素材编号时明确标记为画布待绑定稿。

## 使用

完整 skill 位于 [rehedong-seedance-25](rehedong-seedance-25/SKILL.md) 目录。中文展示名称为「热河东 sd2.5 提示词」，技术标识与调用名保持 `rehedong-seedance-25`。

将完整目录放入支持此格式的工具的 skills 目录后调用，例如：

```text
请用 $rehedong-seedance-25，基于我的剧本和画布参考素材写前30秒的提示词。
不用精准时间戳，关注情绪、表情和真实性，最后附负面提示词。
```

该 skill 编写提示词，不直接提交视频生成任务。

## 文件

- `SKILL.md`：主要规则与输出模板。
- `agents/openai.yaml`：中文展示名称和默认调用提示。
- `references/`：素材绑定、表演导演、任务模式、示例与来源。

## 来源

基于用户指定的 `sd25-pe 0.1.1`，结合 Seedance 2.5 手册中30秒长视频的写法进行个人定制。具体继承规则与个人覆盖见 [来源说明](rehedong-seedance-25/references/sources.md)。本项目为热河东个人定制版本。
