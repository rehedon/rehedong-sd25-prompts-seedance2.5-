# 热河东 sd2.5 提示词

## 定位与已确认偏好

主要服务热河东在画布中用多个角色、场景、动作或声音参考创作影视视频。默认保留多参设计，输出能指导模型表演和摄影的完整 Prompt；只有用户明确要求纯文字生成时，才省略参考层。

继承 sd25-pe 的故事合同、素材逐份负责、主体一一映射、对白账本、生成／编辑／延长路由和最终检查。重点采用官方“30秒长视频”章节的多模态参考、全局设定、分段动作和情感解释方法，而不是只套基础短提示词的四个标题。

**用户偏好：不要精准时间戳。** 默认用“开场／阶段一／情绪转折／收束”或已有镜号组织。用户说“前30秒”，意味着选取适合该时长的开头剧情，不自动写成 `0–5秒` 等时间表。只有本次明确要求按秒控制时才加时间段；镜号不是秒数。原稿已有数字时间线但本次没要求保留时，按此偏好转成顺序与相对节奏；明确锁定的时间点则保留。

**单次生成上限：30秒。** 每份独立生成 Prompt 对应的视频最长30秒，可以更短，不强行凑满。超过30秒的整体创作需求按剧情与动作衔接拆成多份 Prompt，每份都包含完整参考、导演结构与末尾的负面提示词；不把多段写在一份 Prompt 中冒充一次生成，不为塞进30秒删台词或加速表演。该上限是热河东的工作流约束，不是对平台所有模式能力的断言，不启用超长模式绕过。分段和延长规则见 [task-modes.md](references/task-modes.md)。

本 skill 负责提示词及必要的画布素材绑定草稿，不提交生成任务、不改素材、不自动升级文件。用户要求查看或重写 skill 时，处理文档本身，不执行视频提示词工作流。

## 开始前按需读取

- 多人、画布素材缺失或节点映射不清：读 [canvas-reference.md](references/canvas-reference.md)。仅给剧本的多参请求也读此文件。
- 30秒剧情、多次情绪转折、真人或复杂表演：读 [film-direction.md](references/film-direction.md)。这是主要创作路径，不因“只给一个 Prompt”而省略。
- 编辑、延长、首尾帧、白模、宫格或整体需求超过30秒：读 [task-modes.md](references/task-modes.md) 的对应小节。
- 核对来源、平台限制或维护：读 [sources.md](references/sources.md)。常规生成无需每次联网。
- 成品形态与回归检查见 [examples.md](references/examples.md)，不把示例题材和人物当成通用默认。

## 一、先锁定故事，再安排表演

读取用户剧本及相邻情节，明确本片段的起止点。内部记录主体数量、人物关系、关键道具归属、场景、事件因果、原台词和最终状态。范围是“前30秒”时，选择从开头连续发生、能自然收束的一组事件；不要把整场或整篇硬塞进去，也不要把片段后面的新情节提前搬来。

保真改写可细化动作、呼吸、停顿与镜头，不改变角色决定、事件结果和已有事实。明确要求原创或扩写时，才在授权范围补剧情／对白。用户只给“你一个外人”就只保留这几个字；不补后半句，不把潜台词、心理说明或人物关系拼进对白。

为每段建立内部对白账本：说话人、原文、说话／吟唱／旁白、音频绑定、语言、画内外来源和发生阶段。手机屏幕文字不是台词。只给声音绑定而没有台词原文时保留该职责，不猜写内容。不自动增加普通话或地域口音。

随后确定本段的**表演核心**：角色此刻在做什么、想维持什么、被什么打断、情绪怎样变化。将“难过”“震惊”等标签落实为可辨认的行为过程；不把真实情绪简化成不断流泪。已经在哭的角色不能为了制造转折被改成前半段完全无泪。

只对会改变核心身份、数量、结果、编辑对象、唯一母版或延长方向的歧义合并问一个问题。缺少真实画布编号按待绑定流程继续，不要求用户重新上传素材才能写。已有用户映射即使素材不可读也继续保留。

## 二、多参优先，引用必须真实

顺序是：用户指定绑定 → 文字职责 → 实际可见内容；文件名和上传顺序不证明身份。区分角色外形来自哪份参考、本段表演由什么剧情决定、谁在何时发声。

- 实际引用已知：原样保留 `@图片N`、`@Image N`、`@视频N`、`@音频N` 或真实画布标签，一项主体一行职责。不自动改号或翻译标签。
- 看不到素材：保留用户标签与职责，不编造外貌、发型、服装细节、音色或边界帧，不声称已看画布。
- 只给剧本、没有实际标签：默认继续做多参，使用明确的语义槽位，如 `〔唐易人物参考〕`、`〔灵堂场景参考〕`。在正文前只加一句：`画布待绑定稿：将〔名称〕替换为画布里的实际素材引用后使用。` 这些不是上传成功的素材、不是平台语法，不得变造为真实 @ 编号。仅保留必要槽位，不为每个普通道具创建一张图的要求。
- 用户明确要纯文字生成：不创建素材槽位，按其要求省略多模态参考层。

参考层公式：**素材引用＋唯一角色／对象＋采用维度＋保持关系＋必要的排除范围**。

人物图片锁定脸、发型、服装及可见特征；场景图片锁定布局、材质和指定光线；动作视频按指定维度提供运动和摄影；声音素材逐人绑定音色或台词。图片中的静态表情不锁死整段表演，除非用户要求该表情固定。多次在剧情中引用素材只用于身份回归、场景切换和声音绑定，不机械每句重复。

单人图不定义两个出场角色；同一人的多视角要声明共同定义一个人。明确角色分别绑定；背景群体可使用合适的群体参考。用户绑定已完整时不启用额外相似素材。已知的可用但未采用素材必须逐个列入 `【未采用素材】`，清单未知则不编造。

## 三、套用30秒长视频导演公式

这套结构适用于30秒以内的片段；文字长度随事件、对白和转折变化，不设固定字数、不固定镜头数。默认输出以下完整结构，单镜头可减少阶段，但保留必要的参考、全局和表演信息；每份 Prompt 最后一个板块固定为 `【负面提示词】`。

```text
【总述】
主体＋地点＋核心事件＋情绪变化＋镜头形式。

【多模态参考层】
每个角色、场景、关键物件、动作和声音的实际绑定；没有真实标签时按待绑定规则填写。

【全局设定】
基础环境与质感：时间、地点、空间关系、现场氛围及相关材质。
视觉风格与光线：与素材和作品一致的风格、光源、景深及可见效果。
镜头语言：一镜到底或切镜策略、主要观察对象、视角与运动方式。
人物造型：引用角色素材，补充文字已确定的服装／状态，不重造角色脸。
表演核心：起始情绪或工作状态、触发事件、情绪方向及关键外在变化。
声音原则：说话、吟唱、环境声、动作音效、音乐的来源与主次。

【情绪与动作分镜】
阶段一｜戏剧功能
动作与表情：起始姿态、正在做的事、刺激、即时反应及随后变化。
镜头与声音：摄影怎样跟随或揭示，谁说哪句原话，何时听见相关声音。
表演意图：一句与具体动作对应的情感／镜头潜台词。
承接状态：必要时写位置、道具、视线、呼吸和动作的落点。

随后各阶段按因果推进；最后一阶段给出明确的收束画面与声音状态。

【全局收束】
重申贯穿片段的核心身份、服装、空间、道具和声画关系，避免重复整套设定。

【负面提示词】
结合本段实际内容，写出需要避免的身份、表演、动作、时序、摄影或声音错误，以及用户明确排除的内容；用简短具体的禁令，不照抄通用词库。
```

将模板说明替换为具体创作指令，删除不适用的行。表演意图是给生成模型的导演指令，保留简短、有效的心理动机；不输出分析过程或长篇人物小传。转折段不能只写“更难过了”，必须有动作／表情与意图的配合。

片段总时长、画幅、分辨率、帧率和声音开关交给画布参数，不写成剧情正文要求；必要时在 Prompt 前给片长建议，单段不得超过30秒。以片长检查事件是否能演完；长台词、哭唱、阅读消息和反应都要有展开空间。用“读完消息才……”“说完后短暂停住”“随后一口气没接稳……”控制相对时序，不用精确秒点代替导演。

## 四、情绪、表情和真实感是交付内容

完整公式：**情绪起点＋触发事件＋可观察反应＋应对动作＋情绪落点＋镜头／声音反馈**。不是每个阶段都必须改变情绪；倾听、等待和持续动作也应写清角色注意力。

每次转折选少量主要表演通道：视线、眉眼、嘴唇／下颌、呼吸、手或身体重心。让它们有先后、强弱和恢复，不同时安排所有微表情，不把自然演技写成逐帧面部操控。外放表演可以真实，不强行把哭喊改成含蓄落泪。

真实性分三层：心理反应有原因；动作符合重力、接触和身体能力；材质与光线属于同一个环境。真人写实镜头保留自然皮肤起伏、真实布料受力、泪水路径和手持物反馈，不自动新增雀斑、疤痕或改变参考脸。动画按既定风格表现可信情绪，不一律添加真人毛孔。

镜头要能看见重要情绪变化。因果揭示先让刺激可辨认再呈现反应；剧本明确的悬疑延迟除外。不能一边要求面部细节清晰，一边整段远景或剧烈绕拍。每次切镜写清动作、视线或声音的衔接；一镜到底不混入反打跳切。

## 五、输出边界与最终检查

单段任务绑定齐全时只输出一个完整 Prompt；缺绑定时只加上述一句待绑定说明，再输出完整导演草稿。整体需求超过30秒时，简短说明拆分并输出多份独立 Prompt，每份最多对应30秒；用户只要“前30秒”时不扩展后续。不要额外堆素材规划表、评测过程、优化说明或来源列表。用户要求方案、解释或多个独立镜头时按其要求交付。

待绑定槽位只允许出现在明确标识的待绑定稿中；正式可提交稿必须全部替换。真实素材不能混为计划素材。用户既有标签不可读取也仍可用于正式文字优化，不因打不开附件退回待绑定状态。

每份完整 Prompt 必须以 `【负面提示词】` 结束，包括纯文字生成、待绑定稿、编辑和延长；`【未采用素材】` 放在参考层之后，不占用末尾位置。负面板块是提示词文本结构，不声称平台另有独立负面输入框或保证模型完全遵从。

负面提示词公式：**本段易出错的对象＋需要避免的具体错误**。按镜头选择身份串脸／复制、表情突跳／僵硬、身体与接触错误、道具瞬移、刺激前抢先反应、无意跳轴／闪烁、错人发声／漏改台词等相关项；不要求每类都写，不添加镜头未涉及的对象。针对性排除集中放在末尾，正向段落仍写清应当发生的行为和连续性。

不添加“电影级8K”“完美物理”等空泛包，不默认禁用所有音乐、字幕或场景文字。不得用“禁止哭喊／禁止表情变化”覆盖剧本表演，也不以“无文字”禁止剧情中的手机消息。无对白不等于静音，无配乐不等于去掉环境声；负面词不能与正向剧情、风格或声音要求相冲突。

确有需要时在 Prompt 之前放一条简短制作／参数／素材提示，说明精准屏幕文字、片长拆分、平台限制或上传别名；负面板块之后不追加制作说明或其他正文。编辑、延长等范围规则见专项文件。

提交前核对：

1. 仍然是画布多参路径；已知引用保真；未知引用明确待绑定；未擅自降级成纯文字摘要。
2. 参考层、全局设定、表演核心和分段导演都有实质内容，不只是换标题复述剧本。
3. 每份独立生成片段不超过30秒；超长需求已合理拆分。默认没有数字时间段、精确停顿时长或帧级保证；片长仅用于参数与节奏预算。
4. 原人物、数量、因果、原台词、吟唱方式、道具归属和结局完整；文字没有误作对白。
5. 每个关键转折有可见刺激、表情／身体变化、声音变化和情绪含义，且摄影视角能呈现。
6. 素材中的脸、服装和场景不会被角色描述覆盖；身份一致与表情变化互不冲突。
7. 动作与对白能在片长内展开；保持相对节奏、镜间方位、呼吸、道具和声音连续。
8. 没有伪造观察、未替换的普通模板占位、无关负向词或画面与声音相互矛盾的要求。
9. 每份 Prompt 的最后一个板块都是实质性的 `【负面提示词】`；内容针对本段，不误伤原剧情、表情变化、声音或场景文字。
