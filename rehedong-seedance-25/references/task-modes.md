# sd25-pe 基础控制与专项任务

主要任务仍是画布多参生成；本文件保留编辑、延长及关键帧等必要分支，避免这些分支挤占默认导演写法。每次生成的视频最长30秒是本 skill 的个人工作流上限；入口限制更低时采用更低值，入口支持更长也不自动放宽。来源快照见 [sources.md](sources.md)。所有完整任务 Prompt 均以 `【负面提示词】` 结束。

## 超过30秒的内容如何拆分

超过30秒的整体需求拆成多份独立 Prompt，按事件、对白完成点或情绪落点划分，每段都能在不超过30秒内自然演完。整片可由多段组成，不能将这些段落合成一次超长生成，也不把所有片段都机械写满30秒。只请求开头或某一段时，仅交付该范围。

每份保留独立可用的素材绑定、全局设定、分段导演、收束和末尾负面提示词，不以“同上”省去关键身份与声音职责。下一段开场承接上一段结束时的位置、视线、动作、道具、光线和声音；尚未生成的上一段结果不虚构为真实视频编号。需要绑定上一段结果时明确标为待绑定素材。

片段编号表示生成批次，不是时间戳；必要时在各 Prompt 之前给画布片长建议。用户指定整体时长时按该预算分配，默认仍不写逐镜秒数。若台词或动作超过单段容量，保留原文与因果，增加片段或说明预算冲突，不静默删减或倍速播放。

## 生成、编辑、延长的判断

修改同一原视频里的对象、区域或声音，且画幅和基本时长相容：视频编辑。原片前后添加新内容：视频延长。其他由文字及素材创作新画面：视频生成。粗细白模重渲染通常属于参考生成。

核对可读原片的真实比例与时长。目标画幅不同，或改变总时长而没有明确续写方向时，按参考生成处理。基线以约0.3秒作基本时长容差；只有缺少当前入口规则时作为参考，不当作所有 API 保证。当前入口明确支持其他处理方式时按已确认能力判断。

不可读取原片时，用户明确说横屏转竖屏、缩短或改总时长，足以保守判断规格冲突；只有一个目标数值则不声称已确认冲突。仅因使用“改成”“转换”等动词不自动路由为编辑。

因规格冲突进入参考生成时，在生成目标句后只加一次 `请注意这不是视频编辑。` 源片用于指定内容、时序、镜头或声音参考，不承诺逐帧相同。其他任务不加此句。

## 参数与时序

继承基线：普通生成参数在界面设置；编辑跟随输入画幅和基本时长；首帧／首尾帧画幅跟随首帧；延长跟随源片画幅。首尾图画幅不一致时在 Prompt 外提示调整。

热河东偏好无精准时间戳：本次未要求时间表时，生成用阶段和动作条件。用户只说“前30秒”不触发秒数表。明确给定的编辑生效区间、音频区间和锁定时间点属于任务范围，保留原样；不能以偏好为由把局部编辑扩成全片。

普通段落不写总时长和画幅指令；片长建议放在 Prompt 前的画布参数说明中，每份最长30秒。超过30秒的请求走分段生成，不启用超长模式。保留编辑生效区间不等于允许生成超长成片。

## 视频编辑

指定母版超过30秒时先说明需拆成不超过30秒的工作片段，给出分段方案与原片区间对应；不擅自裁剪源素材，不把局部修改扩成全片，也不承诺一次返回超过30秒的完整编辑成片。原片定位时间仅用于范围识别。

编辑公式：唯一母版＋具体对象／区域＋从A改为B＋生效范围＋保持内容＋时间线继承。用户在画布中圈选时注明实际颜色、框内／框外、箭头方向或地标；没有标注就不虚构红框。

```text
【编辑目标】
编辑实际源视频，改变明确对象的指定属性。
【母版与目标素材】
源视频是唯一编辑母版；逐份绑定目标素材及采用范围。
【编辑范围与时间线】
目标数量、区域和生效范围；继承原对象的出现时机、轨迹、速度、遮挡和离开状态。
【保持内容】
除明确修改内容外的其他画面、动作、声音和镜头要求。
【负面提示词】
针对本次编辑，禁止误改范围外的主体、串用目标素材或破坏需继承的动作与声音；替换成当前任务的具体对象和错误。
```

完整读取时盘点相关人物、真人、模型、道具及背景；读取不完整时不声称穷举。局部修改必须包含范围闭环，实际编号替换：`除以上明确修改对象外，@视频1中其他可见人物、道具和背景元素保持原样，不参与替换或删除。`

用户要求只保留特定对象时，改为 `除以上明确保留对象外，删除@视频1中的其他可见主体；不新增未指定对象。` 不同时保留两种相反闭环。

跨类别替换明确删除原主体，由目标覆盖原运动槽位，不让二者共存。范围盘点不能扩大用户已指定目标素材集合；未点名素材继续排除。

只改声音时指定说话人／声音类别、区间及变化，保留其他声音、画面、动作、镜头和原有说话时点。去BGM不写成全静音。改语言与台词时不能同时承诺原口型像素不变与新口型绝对同步；需要重做口型则纳入范围。

## 视频延长

单次目标输出仍不超过30秒。若入口返回“原片＋新增内容”的合并结果，按合并后的总时长检查；超过30秒时改写为独立续接片段的参考生成，保留原片边界约束，每段最长30秒，再用于后期衔接。此时明确它是续接生成，不冒充平台延长操作，不挤压或缩短原片。源片、新增段和合并结果的时长分开判断，不因新增段不足30秒就把更长合并结果算作合规。

区分前后方向。“接着／继续结尾”可判断向后；只有“延长”且无上下文时问方向。额外素材先明确职责，原片边界控制优先。

向后：声明向后延长源片，新片段起点承接原尾帧的主体姿态、朝向、道具、空间、机位、光线、声音和运动；之后展开新事件，给出结束状态。

向前：先写前置事件，新片段最后到达原首帧状态；后续人物、物件或特效不提前登场。不可读边界时只写上述衔接关系，不编造具体状态。

两类都要写明主体始终是同一个连续对象，不复制或分裂，身体／物体部件数量稳定。连续镜头保持运动自然；用户需要转场时说明转场触发、前后画面及声音连接，不统一禁止切镜。

同时修改旧片与延长时，先编辑得到新母版，再延长新母版。输出 `步骤一：` 和 `步骤二：`，第二步明确绑定第一步结果；只是新增人物出现在延长段而旧片不改时只做延长。

每步 Prompt 均以针对该步的负面提示词收尾，例如避免边界处人物复制、道具瞬移或无依据的声线突变；不把这些限制泛化为禁止剧情需要的新人物、转场或情绪变化。

## 首尾帧、宫格、白模

首帧必须独立写 `@图片N作为首帧。`，尾帧独立写 `@图片N作为尾帧。` 保留用户标签形式。随后分别描述构图、主体姿态和物品状态；角色参考补身份，不覆盖边界。中间关键帧按顺序逐张指定可见状态，并用动作连接，不承诺逐像素复刻或静态停顿。

宫格明确读取顺序、各格镜头职责、占位人与最终人物的绑定。参考叙事与构图；格框、线条、箭头、文字标注不进入成片，用户要求漫画效果时例外。

粗白模提供动线、站位、摄影、光影和节奏；逐个几何体映射最终角色／道具，再写剧情与表演。细白模已有结构，保留结构与运动，指定材质、光线或风格变化。四肢动作只细化当前运动所需的顺序，不给所有关节编排无关动作。制作坐标轴、轨迹线、控制器与相机锥体不进入成片；不自动改动原素材。
