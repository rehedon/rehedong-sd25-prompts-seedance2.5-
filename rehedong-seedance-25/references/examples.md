# 画布多参成品示例与回归场景

示例基于用户提供的《用大金镯换朵小黄花》开头编写，展示新的交付深度。参考槽位是准备稿，不表示已经拿到这些图。具体素材、题材和表演不能作为其他任务的强制默认。

## 只有剧本时：前30秒、无精准时间戳

输入：唐易披麻戴孝从面包车下来，举话筒哭唱“我的妈妈，我滴亲，你怎舍得弃我而去！”。跪着的家属A说“这小姑娘嗓子可真亮.....”，家属B说“不愧是专业的”。手机显示拒聘消息“很遗憾，您与我们岗位不匹配......”。唐易哭得更伤心，说“天哪，妈妈！”。用于画布多参，没有提供素材编号。

交付示例：

制作提示：手机消息的准确字形可用准备好的屏幕素材或后期叠加完成。

画布待绑定稿：将〔名称〕替换为画布里的实际素材引用后使用。

【总述】
白天的灵堂外，唐易下车哭唱，家属赞叹她的嗓音；招聘拒绝的消息突然闯入，她原本熟练的哭唱逐渐被真实的受挫打乱。采用写实剧情片的切镜方式，让声音与人物反应自然连接。

【多模态参考层】
唐易的面孔、发型和孝服对应〔唐易人物参考〕，本段的眼神、呼吸和哭唱表演按剧情变化。
家属A的面孔与衣着对应〔家属A人物参考〕。
家属B的面孔与衣着对应〔家属B人物参考〕，两位家属的外貌和台词不互换。
灵堂外的布局、陈设、面包车停靠区域和跪坐区域参考〔灵堂场景参考〕；图中未绑定的人物不替代唐易或两位家属。

【全局设定】
基础环境与质感：白天，面包车停在灵堂外，家属跪在灵堂旁，车门至灵堂之间留出唐易下车站稳的空间。
视觉与光线：使用自然日光，脸部有柔和的明暗起伏，孝服保持布料纹理和动作产生的褶皱，眼泪沿脸颊自然下滑。
镜头语言：先在中景建立人物与环境，随后按吟唱、家属回应、手机消息和情绪变化切换观察对象；面部转折留在可看清眼神与嘴部的近景中。
人物造型：唐易全程保持人物参考中的脸、发型和孝服；右手持同一支话筒，查看手机时用左手持同一部手机。
表演核心：开头已经泪如雨下，声音仍响亮、唱腔有熟练的节奏；看清拒聘消息后，换气和发声开始失去原来的规律，让真实委屈进入正在完成的哭唱。
声音原则：唐易是吟唱而非念白；家属低声交谈，手机提示音短促明确，保留现场衣料、脚步与环境声。

【情绪与动作分镜】
开场｜哭唱着出现
动作与表情：唐易从车门内迈下，一脚踩实地面后转移重心站稳。右手举着话筒，脸上已经有泪痕；吸气后带着哭腔拉开声音。
镜头与声音：从车门一侧的中景轻轻跟随她落地并转到侧前方，保留背景灵堂的位置。唐易吟唱：{我的妈妈，我滴亲，你怎舍得弃我而去！} 句中有自然拖腔和换气，不加新的词句。
表演意图：她正在完成一场熟悉的哭丧表演，情绪外放，发声仍有控制；画面中的眼泪从一开始就存在。

随后｜家属的认可
动作与表情：跪着的家属陆续将目光转向唐易，反应有先后。家属A听着她的声音，略向家属B偏头；B仍看着唐易，接过话头。
镜头与声音：以唐易的吟唱尾音衔接两人的中近景。家属A低声说：{这小姑娘嗓子可真亮.....} 家属B随后回应：{不愧是专业的。} 两人各说自己的话，未说话者自然聆听。
表演意图：他们关注的是唐易唱得好，注意力仍停在这场仪式的表演上。

转折｜手机里的消息
动作与表情：手机响起。唐易保持右手握话筒，左手取出手机，低头读屏幕。画面明确显示：“很遗憾，您与我们岗位不匹配......”。读完后，她的目光停住，原本规律的换气短暂卡住，握手机的手逐渐收紧。
镜头与声音：先看见她低头，再沿视线切到手机屏幕，随后回到面部近景；提示音落下后留出读懂消息与情绪反应的空间。
表演意图：消息触及她自己的处境。变化先发生在注意力、呼吸和手上，再进入声音，不用立刻夸张瞪眼表现打击。

收束｜哭腔里涌进委屈
动作与表情：唐易抬起眼，左手的手机停在胸前下方，右手仍握着话筒。她想接回原来的哭唱，一口气却没接稳，眉间和嘴角绷紧，接着放声哭喊，新的泪水沿已有泪痕滑落。
镜头与声音：面部近景轻轻靠近，唐易喊出：{天哪，妈妈！} 声音比之前更不稳定，字尾带着没收住的哭腔。镜头留住她喊完后的呼吸与眼泪，不急着切走。
表演意图：哭声仍发生在工作里，此刻却容纳了她自己的委屈；保留剧本中“哭得更伤心”的外放幅度。

【全局收束】
保持唐易和两位家属的身份、孝服、话筒与手机的手部分工、灵堂方向和日光连续。拒聘消息看清之后才出现新的情绪转折；手机文字只显示在屏幕上，不被人物或旁白朗读。各句对白沿用原文，阶段之间以动作、视线和声音自然接续。

【负面提示词】
不要混淆唐易与两位家属的面孔、服装或台词，不复制同一角色；不要把开场已经存在的泪痕清空，不在读懂拒聘消息之前提前演出新的受挫反应，不让表情突然跳变或僵硬定格；避免手指与话筒、手机穿插，道具凭空换手或瞬移；不要让家属整齐同步转头，不在情绪转折时无故跳切到空镜；不要把吟唱改成普通念白，不新增或漏掉原台词，不把手机消息变成人声朗读；避免过度磨皮、泪水漂浮和无依据的光线闪变。

## 真实映射到达后的处理

例如用户后来明确“唐易@图片6、家属A@图片2、家属B@图片4、灵堂@图片1；@图片3和@音频2不用”：

- 统一替换四个语义槽位，沿用用户指定编号；删除待绑定说明。
- 参考层之后增加 `【未采用素材】`，分别列出 @图片3 和 @音频2 及排除用途。
- 不因图号顺序重排角色，不把没读过的唐易图写成特定发型或面部特征。
- 保留剧情中的表演变化；不用静态角色图的笑脸覆盖哭戏。

## 验收场景

检查实际输出的行为和内容，不以标题字面匹配当作质量证明。

| 请求 | 应有行为 |
|---|---|
| 只给剧本，写前30秒，用画布多参 | 有待绑定的多模态层、完整全局设定、情绪与动作分段；没有杜撰实际 @ 或精准秒表 |
| 写一段60秒的完整剧情 | 按事件与对白分成多份最长30秒的独立 Prompt，保留承接；不启动超长模式，不把全部剧情压成一次30秒生成 |
| 只要一个短镜头 | 不为满足上限强行拉满30秒，仍在末尾写该镜头相关的负面提示词 |
| 30秒源片后继续一段 | 不交付超过30秒的单次合并结果；改成独立续接生成，承接原尾帧，不缩短原片 |
| 已明确 @ 标签，但附件不可读取 | 原样保留引用与职责，直接写 Prompt，不变成待上传任务或假装观察 |
| 只有参考图和角色名，无剧情 | 问最小创作目标，不自行编造核心事件 |
| 用户本次明确“纯文字” | 省略参考层，尊重本次任务，不强制画布槽位 |
| 用户本次明确要求按秒 | 按要求编排或保留数字区间，不让长期偏好覆盖本次明确指令 |
| “更伤心”，前面已经泪如雨下 | 不删掉前面的泪；用呼吸、音色、注意力和动作改变表现新的层次 |
| 笑着掩饰紧张 | 笑容与具体应对动作相连，不只是“表情复杂” |
| 仅在给定时段改杯子 | 保留生效区间与母版，不因无精准时间偏好而扩成全片 |
| 同一人物多张正侧面图 | 单一人物、多视角分工；表情仍能随情节变化 |
| “不要BGM，保留说话和雨声” | 去音乐，保留对白和雨声，不写全片静音 |
| 哭喊场景带手机文字，结尾加负面板块 | 禁止身份串用、提前反应、错误朗读等具体问题；不禁哭喊、表情变化或剧情文字 |
| 有制作提示、未采用素材或多步编辑 | 提示放在 Prompt 前，未采用素材放在参考层后；每份完整 Prompt 的末尾仍是负面提示词 |
