# 30秒长视频公式：无精准时间戳的导演写法

来源是手册的30秒长视频与真人人物章节；热河东明确偏好去掉精准时间戳。保留其“多模态参考＋全局设定＋分段动作／情感解析”的实质，改为因果、动作完成条件和相对节奏组织。单次生成最长30秒，每份提示词最后附针对性的负面提示词。

## 三层写法

**参考层**：绑定素材、声明采用范围、锁定身份与空间。清楚写谁参考谁，控制什么，不控制什么。

**全局设定公式**：基础环境与质感＋视觉风格＋镜头语言＋人物造型＋表演核心＋声音原则。全局决定整段成立的条件，不负责替代每段表演；针对性排除统一收在末尾 `【负面提示词】`。

**单段导演公式**：阶段主题＋动作／表情指令＋镜头／声音调度＋情感或镜头潜台词＋结束状态。字段可合并成顺畅自然段；情绪转折处应清楚区分可见行动与该行动的情感意味。

不强制三段或五段，不安排整齐等长的情绪格子。根据已有事件与台词选择变化节点，依次写“起初、听见后、看清后、等对方说完、停住、随后、最终”。大动作、哭唱、阅读与理解都需要时间，不能让角色在一个瞬间完成多种反应。

## 人物公式如何与角色参考相容

手册按年龄背景、皮肤、面部细节、眼神、头发、服装、体态／气质拆解人物。多参时先锁定参考身份，再选与镜头有关的细节，不把七个维度重新编一遍。

| 维度 | 多参中的处理 |
|---|---|
| 年龄、关系、身份 | 沿用剧本，不从脸猜国籍／族裔或亲属关系 |
| 皮肤、五官、发型 | 来自角色图；不可读时只写引用职责，不设计新外貌 |
| 眼神 | 写看向谁、停留在哪、何时移开；“含情脉脉”不能替代这些动作 |
| 衣着与材质 | 服从角色图和剧本，关注走动、握持、抬手时布料怎样受力 |
| 体态 | 写支撑腿、肩背、重心、手与物的接触；不把姿态自动解释成性格 |
| 真实感 | 真人风格表现自然皮肤、发丝、光线和表演；不擅自添加参考图没有的伤疤、雀斑或过度磨皮 |

## 情绪不是形容词堆叠

写前内部确定：当前情绪是什么；角色正在努力做什么；刺激何时出现；其注意力和行为如何被改变；变化最终落在哪里。

用少量表演通道构成一条连续变化，例如：

```text
看清消息后，视线停在屏幕上；刚才顺畅的换气短暂卡住，握手机的手慢慢收紧；她重新抬头继续说话，句首仍想维持原来的语气，句尾却逐渐发紧。
表演意图：她试图把刚受到的打击藏回正在完成的事情里，但声音先泄露了情绪。
```

示例仅演示关系，不给所有角色套用同一套微表情。触发必须发生在反应之前；悬疑故意先给反应后揭示原因时遵循剧本。

### 表演与潜台词

潜台词不是新增台词。可写“她是要稳住对方”“他在等待解释”“这是礼貌而非认同”，但后面必须有眼神、声音、动作等可以执行的依据。不能只写“内心波涛汹涌、灵魂崩塌”。

相同动作允许不同动机：礼貌微笑、安慰微笑、松一口气后的微笑，在出现时机、目光和呼吸上要有区别。保持角色脸一致，不强制表情一致。

哭戏区分起始状态与变化：已在流泪就保留眼泪；新的刺激可以改变呼吸规律、发声方式、手部紧张、肩背支撑，而不是凭空再启动一遍“从平静到泪崩”。不能因为强调真实就把剧本的高声哭唱全部改成沉默克制。

## 三层真实性

- 心理真实：注意力、反应有因果；先听清／看清，再理解和行动；群众各自有自然反应，不整齐同步转头。
- 身体真实：下车先落脚、转移重心，再抬身；抓取有手指接触、承重和松手；拿手机时话筒由哪只手持有始终可追踪；呼吸、说话和吞咽不能同时满负荷。
- 画面真实：主体与背景受同一光源影响；衣服、皮肤、道具具有合适质感；眼泪沿脸颊自然移动，不无中生有穿过皮肤；景深让重要信息可见。

只挑与本镜头相关的物理细节，不给每段附全身关节列表或绝对保证。

## 摄影与声音共同导戏

镜头公式：作用对象＋起始景别／位置＋运动方式与方向＋到达画面＋揭示的信息。保留用户给定参数，但用可见结果补充。

全局选一镜到底还是切镜。阶段内切镜要说明连接理由：接同一动作、接视线对象、接下一位说话人或让声音延续。自然切镜不是每次加特效转场；面部情绪转折不宜被无关空镜覆盖。

声音逐段绑定。台词用 `{原话}`，屏幕文字直接以“屏幕显示：……”描述；不把屏幕文字念出来。吟唱保留曲调感、拖腔和换气，不能改成普通念白。情绪变化可以落在声线、字尾、呼吸或短暂停顿，但不改字、不加方言。

环境声来自场景，动作音效来自实际接触，音乐按用户要求。切到他人反应时，可让主角的无词哭腔在画外延续，不重复新台词；不能凭空安排第二个同音色说话人。

## 节奏验收

以不超过30秒的目标片长粗略试读台词并想象动作能否完成。不靠加快一切塞满故事；如果内容过密，保留因果与原台词，选择合理的本段终点，后续留给下一生成片段。整体需求更长时交付多份独立 Prompt；改变用户指定覆盖范围前简短说明冲突。

结尾停在一个可承接的表情、姿态、道具或空间状态。用户要求继续下一段时，从这个落点接上，而非重演上一段开头。

负面提示词针对已写出的表演与镜头：有刺激再反应时避免抢先变脸；有道具交互时避免穿模或瞬移；真人近景避免表情僵硬和过度磨皮。只选本段相关问题，不把外放哭喊、必要的表情变化、合理的切镜或剧情文字一律禁止。
