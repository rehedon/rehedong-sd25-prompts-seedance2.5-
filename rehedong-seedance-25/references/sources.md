## 明确的个人定制覆盖

- 基线默认纯文字可直接文生视频。本版默认用途已被用户改为画布多参，所以缺少实际标签时写有明确说明的待绑定草稿，既保留工作流也不伪造上传。用户本次要求纯文字时仍回到纯文字。
- 基线一般不允许最终 Prompt 留占位符。本版只允许在明确标注的画布待绑定稿中使用语义素材槽位；正式提交稿仍必须完成替换。此覆盖不适用于普通模板里的动作、台词等未填项。
- 网页30秒样例使用精准时间戳。依用户偏好，改用自然阶段、动作完成条件和相对节奏；用户本次明确要求秒点或给定编辑范围时保留。
- 单次生成最长30秒是用户新增的个人限制。整体长片拆为多份独立 Prompt；延长若返回合并成片，按合并后长度判断，超限改为独立续接生成。平台的超长能力不用于绕过此限制。
- 用户要求每份提示词最后增加 `【负面提示词】`。因此将原全局设定中的排除项集中到末尾，制作与参数提示移到 Prompt 之前；这一格式也用于纯文字、编辑和延长。
- 网页的长篇情感解释压缩成与动作紧密关联的导演意图，但不把表演意图全部删去。
- 原 sd25-pe 自动升级命令不迁移到个人版本。更新作为单独维护任务处理，避免覆盖个人定制。
- 旧1.0的基础四段模板不再是默认路径；主路径采用30秒长视频的全局设定与分段导演结构。

## 平台快照：仅在相关任务用到

来自手册“参数设定”和“功能交互”，不代表所有 API 的永久约束：

- 图片最多30张，输入建议单张4K以内；参考视频最多10段、总时长30秒以内；音频最多10段、总时长30秒以内。合计最多50份。当前界面明确不同则采用当前限制。
- 推荐的主体数量、单段5–10秒、编辑20秒以内属于稳定性建议，不自动变成硬门槛。
- 当次读取的手册记录超长视频入口支持30–180秒；这是平台能力来源快照，本 skill 不走该入口，仍遵守个人单次最长30秒的约束。
- 当次手册记录延长入口源片不超过30秒、单次新增4–30秒，30秒源片可加到60秒；本 skill 不据此输出超过30秒的单次合并成片，超限时改为独立续接生成，也不能推出60秒结果可无限继续延长。
- 约0.3秒的编辑时长容差和参数锁定规则来自 sd25-pe 基线；具体平台有新说明时更新，不冒充本次手册的独立确认。

能读取时才测量实际规格。超限先保留用户指定、核心主体、唯一母版和边界素材；不上传的素材在正文外提示缩减，实际上传但未采用的才进入未采用列表。核心结果无法在限制内保留时合并询问取舍。
